# CoatingBOSS Zoomdocument

Zoom文字起こしから、住宅コーティングBOSSの家族相談用1ページLPを作成するNext.jsアプリです。

## 目的

Zoomで見積説明を受けたお客様が、ご家族に内容を正しく共有できるページを作ります。

## 主な機能

- Zoom文字起こしテキストの入力
- 施工箇所、施工範囲、金額、注意事項などの下書き抽出
- 抽出結果の編集画面
- 確認チェック後のみ公開用URLを作成
- スマホで見やすい1ページLPプレビュー
- PDF印刷ボタン
- 白背景、青基調、営業色を抑えたデザイン

## 重要な運用ルール

このリポジトリには、お客様名、実際のZoom文字起こし、見積詳細などの個人情報・商談情報を保存しないでください。

アプリ上の入力内容はブラウザ内で処理されます。公開用URLは内容をURLハッシュに含める簡易共有方式です。本番運用では、認証付きDBや限定公開URLへの保存に置き換えることを推奨します。

## ローカル開発

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

## 画面構成

1. 本日のご提案内容
2. 施工箇所と施工範囲
3. 施工日数・当日の流れ
4. 金額
5. Zoomで確認した内容
6. ご家族への共有メモ
