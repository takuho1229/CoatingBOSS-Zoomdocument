# CoatingBOSS Zoomdocument

住宅コーティングBOSSのZoom後フォロー用ページです。

特定のお客様の文字起こしや見積内容に依存せず、どのお客様にも送れる「ご家族で検討いただくための共通説明ページ」として作成しています。

最終更新: 共通説明ページ版

## 公開URL

GitHub Pagesを有効化すると、以下のURLで公開されます。

https://takuho1229.github.io/CoatingBOSS-Zoomdocument/

GitHubの `Settings > Pages` で、Sourceを `GitHub Actions` にしてください。その後、`Actions` タブの `Deploy to GitHub Pages` が成功すると公開されます。

## 目的

Zoomで見積説明を受けたお客様が、ご家族に住宅コーティングの内容を共有しやすくすることです。

個別の見積金額や施工範囲を載せるのではなく、以下のような判断材料を網羅的に整理しています。

- 住宅コーティングとは何か
- 水回りで施工できる箇所
- 水回り以外で施工できる箇所
- 期待できる効果
- 見た目の変化
- 施工日数とスケジュール
- 金額を見るときのポイント
- 施工後のお手入れ
- 保証・万が一の対応
- ご家族で確認いただきたいこと

## 主な機能

- スマホで読みやすい1ページ構成
- 白背景、青基調、清潔感のあるデザイン
- 営業色を抑えた説明文
- PDF印刷ボタン
- URL共有前提の静的ページ

## 運用ルール

このリポジトリには、お客様名、実際のZoom文字起こし、見積詳細などの個人情報・商談情報を保存しないでください。

このページは共通説明用です。個別の金額や施工範囲は、別途お見積書で確認いただく前提です。

## ローカル開発

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。
